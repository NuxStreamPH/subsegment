Subsegment ingest reliability and scaling patch

Base: burntoutstaxi/subsegment-gstream, commit b925d1a4425f360905c4d84c2e9b9a570090a5ab
This archive contains the complete patched source, including GitHub Actions workflows.
It does not contain compiled binaries. No changes were published to GitHub.

Changes:
- Replace the total HTTP request timeout with an inactivity timeout.
- Share MP3/ADTS AAC upstream downloads across quality/codec profiles.
- Isolate slow encoders with bounded input queues and cancellation on overflow.
- Coalesce simultaneous output starts before reserving encoder capacity.
- Bound startup time and clean up cancelled/idle/replaced pipelines safely.
- Add reconnect backoff/jitter, error details, metrics and regression coverage.
- Preserve merged ICY metadata for late subscribers.

Build and deploy:
1. Extract the archive and enter the subsegment-gstream directory.
2. Install Rust and GStreamer dependencies listed in README.md.
3. Run: cargo test --locked
4. Run: cargo build --release --locked
5. Stop your service, back up its current binary, replace it with
   target/release/subsegment, and restart the service using your existing config.
   The new settings default automatically; see README.md for tuning options.
6. Monitor one station for at least ten minutes and request several output
   profiles. A shared MP3/AAC station should normally show one active upstream.

Validation completed on the patched source:
- cargo test --locked: 81 passed (GStreamer enabled).
- cargo test --locked --no-default-features: 80 passed.
- cargo check --locked --features gstreamer_only: passed.
- Real-media tests decoded Opus produced by late-joining profiles from shared
  MP3 and AAC sources through both GStreamer and FFmpeg.

Limits:
- Ogg, MP4, and unknown input containers retain dedicated ingests per profile.
- Each output still has its own decoder/encoder; shared PCM is not implemented.
- A full encoder queue closes that output; its clients need to reconnect.
- These queues are not a timed prebuffer and cannot fix sustained bandwidth
  below the source bitrate. Local transcoding does not reduce source bitrate.
- VPS deployment and production soak testing have not been performed.
